How it works
Four steps, about two minutes. Works with any AI that can read your file.

  

    
01
Pick note types
Search by the kind of information (dates, maps, articles, numbers) or tap a subject set. Open any card to see its front and back exactly as Anki shows it.

    
02
Fill the settings
Date, exam, language, deck mode and which extra sources to add — NCERT, Wikipedia, current affairs, PIB.

    
03
Copy & paste
Copy the prompt (or download it as .txt), paste it into ChatGPT / Gemini / Claude and attach your PDF, image, transcript or notes.

    
04
Import in Anki
Save the AI's answer as anki_import.txt → Anki → File → Import. Cards land in your existing note types with your own design.

  






  
FAQ

  

    
Will it create new note types in my Anki?
No. The prompt uses the exact names and field order of your existing note types, and the file header tells Anki which note type each line belongs to.

    
Smart Basic / Smart Cloze — whole or specific modes?
By default the whole note type is selected, and the AI picks the best mode for every fact. Tap “Specific modes chuno” to keep only the modes you want.

    
Why does Anki not ask me for a deck?
Choose “Import ke time main chunoonga” in the deck settings — the file then has no deck column and Anki shows the Deck dropdown.

    
Do the previews show my real card design?
Yes. Each preview is your note type rendered by Anki's own engine with sample content (light mode). Interactive cards are shown as they first open.

    
Is my data sent anywhere?
No. The site is a static page; your settings stay in your own browser. Nothing is uploaded.
